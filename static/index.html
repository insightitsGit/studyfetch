    Representation
    
          
    
            
    Useful for downstream AI?
    
            
    Yes. Outline + retrieval_text + pages + section ids. Prism adds verified_parameters, shield, and graph edges. Relay adds asset_ids and page labels.
    
            
    Traceable to the original document?
    
            
    Yes. document_id → filename / sha256; section_id; page_start/end. Prism metrics add provenance_page + Ed25519. Relay figures resolve at /api/assets/{id}.
    
            
    Context without dumping the PDF?
    
            
    Yes. Each stack prefixes only the heading path. Relay keeps one leaf section. Prism may add one related section via ChorusGraph — not the sibling chapter.
